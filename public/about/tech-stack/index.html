ABOUT

The technology behind cover100

A tech stack is the tools used to build and run a product. cover100.dev describes a coverage workflow that aims for verified tests or documented gaps; the current coverage CLI and the planned agent plugin have distinct roles.

This website

The public site is plain HTML and CSS, with a small JavaScript file for copy buttons and tabs. Cloudflare Workers static assets serves the files directly. The page needs no application framework to explain the workflow or link to its source.

The product

The separate cover100 CLI is written in Go. It collects coverage from Go and TypeScript/JavaScript projects and opens a local, zoomable treemap; its report stays on the user's machine. The agent plugin repository currently holds the proposed multi-agent workflow and language profiles as specifications. This website presents that pre-release plan, including independent test verification and reports of uncovered branches.

Our tools used here

SpecScore keeps the plugin's feature and acceptance criteria in reviewable Markdown files. CodeGrapher is part of the proposed agent research workflow: it can trace source relationships before tests are written. Those tools connect the coverage evidence back to the behavior the tests are meant to protect.

Related projects

Read the plugin specification, try the current coverage CLI, or visit SpecScore for the specification format. The repositories publish their source under Apache License 2.0.
